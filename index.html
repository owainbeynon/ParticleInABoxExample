Finding Valid Wavefunctions for the Infinite Potential Well

Inside an infinite potential well of length L (where V(x) = 0 for 0 < x < L and V(x) = &infty; outside), the wavefunction must go to zero at the walls to satisfy continuity:

\psi(0) = 0 \quad \text{and} \quad \psi(L) = 0
